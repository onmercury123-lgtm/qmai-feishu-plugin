# 商品工作台 · 飞书多维表格插件

版本 0.9.1。多条记录独立修改，下方批量核验并执行立即剔除或恢复。

## 构建与发布

运行 `npm ci`、`npm test`、`npm run build`。仓库已包含 `dist/` 预构建产物，package.json 的 output 为 dist，资源使用相对路径，适配子目录静态部署。每次更新发布需同步重建并提交 dist。

## 使用要求

每位使用者需启动兼容版本的商品工作台并登录企迈。飞书部署成功后，需要将最终插件 origin 加入本机工作台白名单，尚未验证飞书官方托管的本机连接。

本仓库按所有者确认公开，包含业务区域目录，不含企迈账号、密钥、本机操作记录。

## 发布排查

仓库部署文件已做本地安装、20项测试和构建验证。飞书账号发布权限、管理员要求及平台发布结果仍须在飞书端确认，文件校验通过不代表平台发布成功。
