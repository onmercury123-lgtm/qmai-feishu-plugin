# 商品工作台 · 飞书多维表格插件

当前版本：0.9，前端静态插件。读取所选多条记录，逐条编辑，底部批量核验并立即剔除或恢复。

构建：npm ci，然后 npm run build。产物目录 dist。部署方需允许飞书 iframe 加载，并保留与本机窗口连接所需的 opener。

每位使用者需要启动自己的商品工作台并登录企迈。本机工作台只接受列入白名单的插件源；飞书部署后需将最终源精确加入白名单，不要开放为任意来源。

本仓库包含业务区域目录，默认保持私有。按飞书发布表单向审核方单独授权读取；不包含企迈账号、密钥、本机执行记录及运行数据。

尚未通过飞书官方审核部署，尚未验证官方托管环境的本机连接。


0.10.0：简洁白底卡片风；企迈回读成功后自动回填原行“是否已剔除”（复选框或是/否单选）。剔除成功为是、恢复成功为否；回填失败仅重试表格，不重做活动。缺字段或权限不足显示明确提示，不自动创建字段。
